# Codex Manager 사용 안내

## 설치

[Windows 설치 프로그램 받기 · 약 2.5 MB](https://github.com/contentriumkorea/codex-manager/releases/download/installer-v1/Codex-Manager-Setup.exe)를 누르고 받은 파일을 실행합니다. 인터넷에 연결하면 최신 앱을 자동으로 내려받고 검증한 뒤 설치합니다. 이 설치파일은 계속 보관해 사용해도 최신 버전을 설치합니다. 앱 본체 다운로드 용량과 설치 공간은 별도로 필요합니다.

원하는 드라이브에 설치할 수 있습니다. 시작 메뉴에서 **Codex Manager**로 실행합니다. Windows 설정의 **설치된 앱**에서 제거할 수 있으며, 제거해도 프로젝트·대화·백업·사용자 설정은 유지합니다. 기존 앱이 열려 있으면 진행 중인 작업을 마치고 종료한 뒤 설치하세요. 다운로드에 실패했다면 인터넷 연결과 여유 공간을 확인하고 같은 설치파일을 다시 실행하면 됩니다.

## 다른 컴퓨터로 옮기기

### 원래 컴퓨터에서 보내기

프로젝트를 선택하고 **보내기…**를 누릅니다. Ctrl·Shift로 여러 프로젝트를 선택할 수 있습니다. 외장하드 폴더를 고르면 파일과 대화를 함께 복사하고 검사합니다. 완료창에 표시한 상위 폴더를 기억하면 됩니다. 백업 내부 파일명과 폴더를 변경하지 마세요. 이 컴퓨터의 원본은 유지됩니다.

작업 창에서 **현재 프로젝트·단계·파일**, **진행률·처리 용량**, **전송 속도(MB/s)**, **총 경과 시간**, **예상 남은 시간**을 확인할 수 있습니다. 속도와 남은 시간은 최근 전송량에 따른 현재 복사 단계의 추정치입니다. 전체 용량을 검사하는 동안에는 검사한 용량과 경과 시간을 표시합니다.

파일 복사의 100%는 전체 백업 완료가 아닙니다. 이후 **대화 기록 백업 → 백업 검증 목록 생성 → 백업 무결성 검증 → 백업 구성 확인**이 이어지며, 검증 단계에도 처리 용량과 진행률이 갱신됩니다. 전체 검증 후 완료 결과가 표시됩니다. 취소를 누르면 안전하게 중단할 때까지 작업 창을 유지합니다.

### 다른 컴퓨터에서 가져오기

1. 대상 컴퓨터에 Codex와 Codex Manager를 설치합니다. Codex 로그인은 그 컴퓨터에서 진행합니다.
2. Codex 앱을 종료하고 Manager의 **가져오기…**를 누릅니다.
3. 백업이 들어 있는 **상위 폴더**를 선택합니다. 개별 백업 폴더를 일일이 찾을 필요가 없습니다.
4. 발견한 프로젝트의 이름·대화 수·용량을 확인하고 가져올 항목에 체크합니다.
5. **각각 새 프로젝트로 가져오기** 또는 **기존 프로젝트에 합치기**를 선택합니다.
6. 저장 위치를 확인하고 **가져오기 시작**을 누릅니다. 완료 후 Codex를 다시 엽니다.

원래 컴퓨터와 다른 경로를 선택해도 됩니다. 가져온 대화의 현재 작업 경로는 새 위치로 연결합니다. 과거 대화 문장의 경로는 기록으로 유지합니다.

**기존 프로젝트에 합칠 때:** 대상 이름을 유지합니다. 예를 들어 A 백업을 B에 합치면 대화는 B에 들어가고 파일은 B 아래 별도 A 폴더에 저장됩니다. 같은 이름의 폴더가 있으면 A (2)와 같은 새 위치를 제안합니다. 저장 위치는 변경할 수 있습니다.

**같은 대화가 이미 있을 때:** 중복 수가 표시됩니다. **이 컴퓨터의 기록 유지하고 건너뛰기**를 선택하면 기존 대화를 덮어쓰거나 다른 프로젝트로 옮기지 않습니다. 백업 파일은 별도 폴더에 가져옵니다. 기존 대화 교체는 지원하지 않습니다.

손상된 백업이나 외부 첨부·연결 worktree·다른 프로젝트 의존성이 있는 항목은 자동 이식을 진행하지 않습니다. 전체 드라이브보다 백업들을 모아 둔 폴더를 선택하면 검색이 빠릅니다.

### 원래 컴퓨터 정리

대상 컴퓨터에서 파일과 대화를 확인한 뒤 원래 프로젝트의 **삭제…**를 누릅니다. 파일까지 지우려면 **연결된 실제 작업 폴더와 파일도 삭제**를 체크합니다. 외장하드 백업은 별도로 보존합니다.

자동 검증을 거쳐 정리하려면 가져온 대화를 실제로 이어 사용한 뒤 **보내 둔 백업 → 이전 완료 확인**을 실행합니다. 외장하드를 원래 컴퓨터에 연결하고 프로젝트의 **더 보기 → 이전 완료 후 원본 정리**를 사용합니다. 백업 이후 원본이 바뀌면 중단합니다. 중복 대화를 건너뛰었다면 전체 이식을 증명할 수 없어 자동 원본 정리는 사용할 수 없습니다.

## 삭제

프로젝트나 대화를 선택하고 **삭제…** 또는 Delete를 누릅니다.

| 방식 | 복구 사본 | 되돌리기 |
|---|---|---|
| 복구 가능 삭제 | 이 컴퓨터에 자동 저장. 원하는 경우에만 보관 위치 변경 | 작업 내역 · 복구에서 가능 |
| 완전 삭제 | 만들지 않음. 휴지통도 사용하지 않음 | 불가능. 확인 체크 후 실행 |

프로젝트 삭제는 해당 프로젝트와 포함된 대화를 대상으로 합니다. 대화만 삭제하면 프로젝트와 작업 파일은 유지됩니다. 프로젝트의 작업 폴더 삭제는 기본 해제되어 있으며 직접 체크해야 합니다. 다른 프로젝트나 대화가 함께 사용하는 폴더, 보호된 경로와 연결 폴더는 자동 삭제하지 않습니다.

복구 사본은 같은 컴퓨터에서 되돌리기 위한 것입니다. 다른 컴퓨터로 옮기려면 **보내기**로 만든 백업을 사용하세요. 완전 삭제는 앱에서 되돌릴 수 없는 삭제이며 디스크 보안 덮어쓰기 방식은 아닙니다.

## 파일과 대화 관리

- 프로젝트를 두 번 클릭하면 파일이 열립니다. 오른쪽 대화를 두 번 클릭하면 내용을 읽습니다.
- 왼쪽 프로젝트 트리에서 폴더를 열거나 즐겨찾기를 등록합니다.
- 항목을 선택하면 작업 버튼이 한 줄에 나타납니다. 이름 변경은 F2로도 가능합니다. 프로젝트 표시 이름을 바꿔도 실제 폴더명은 유지됩니다.
- 여러 대화 제목은 앞뒤 문구 추가와 찾기·바꾸기로 함께 수정할 수 있습니다.
- 프로젝트나 대화를 대상 프로젝트로 끌어 놓아 합치거나 옮깁니다. 대상 프로젝트 이름은 유지됩니다.
- 파일 위치 이동·프로젝트 합치기·연결 관리는 **더 보기** 또는 우클릭 메뉴에 있습니다.
- 열 제목을 클릭해 정렬하고 다시 클릭해 방향을 바꿉니다. 용량은 자동 계산합니다.

| 단축키 | 기능 |
|---|---|
| Ctrl·Shift 선택 / Ctrl+A | 여러 항목 / 표시된 항목 전체 선택 |
| F2 / Delete | 이름 변경 / 삭제 선택창 |
| Ctrl+C / Ctrl+X / Ctrl+V | 복사 / 잘라내기 / 붙여넣기 |
| Ctrl+Z | 지원되는 최근 작업 되돌리기 |
| Ctrl+F / F5 / Alt+← | 검색 / 새로고침 / 뒤로 |

입력창에서는 일반 텍스트 편집 단축키로 작동합니다. 완료된 프로젝트 이동·합치기와 완전 삭제는 Ctrl+Z로 되돌릴 수 없습니다.

## 저장소와 작업 내역

여러 Codex 데이터 위치를 사용했다면 **다른 위치 찾기**로 검색하고 목록에서 전환합니다. 원래 Codex의 프로젝트 연결을 우선 사용하며, 옛 대화는 폴더·부모 관계를 참고해 분류합니다. 연결 확정이 필요한 경우 안내합니다.

**작업 내역 · 복구**에서 완료·실패·미실행 항목과 변경 위치를 확인합니다. 중단된 가져오기는 같은 백업으로 이어서 복구할 수 있습니다. 외장하드 문자가 바뀌면 복구 화면에서 새 위치를 고릅니다. 다른 백업으로 바꿔 이어서 처리하지 않습니다.

## 업데이트

시작할 때 최신 정식 버전을 확인하고 미리 다운로드·검증합니다. **지금 업데이트**를 누르면 준비된 버전을 설치하고 다시 시작합니다. 내려받는 중에 누르면 준비 직후 이어서 설치합니다. 파일 작업이 진행 중이면 완료를 기다립니다.

시작에 실패하면 이전 프로그램으로 되돌립니다. 설치 프로그램으로 설치한 경우 Windows 제거 기능도 유지합니다. 설정은 `%LOCALAPPDATA%/ProjectConversationManager`에 보관되며 프로젝트 데이터와 별개입니다.

포터블 버전은 실행 파일과 `_internal`을 포함한 폴더 전체가 필요합니다. 새 폴더에 압축을 풀고 `CodexManager/CodexManager.exe`를 실행하세요. 실행만으로 시작 메뉴·바탕화면 바로가기나 제거 프로그램을 등록하지 않습니다.

설치형과 포터블 모두 Manager 설정·작업 내역·자동 복구 사본은 `%LOCALAPPDATA%/ProjectConversationManager`에 저장합니다. Codex 대화는 앱에서 선택한 Codex 데이터 위치(기본 `%USERPROFILE%/.codex`)에, 실제 작업 파일은 각 프로젝트 폴더에 있습니다. 프로그램만 복사해도 프로젝트·대화·Manager 설정이 함께 이동하는 것은 아니므로 작업 이전에는 **보내기 / 가져오기**를 사용하세요. 새 컴퓨터의 Codex 로그인은 별도로 진행합니다.

## 검증 범위

가져오기·합치기·중복 유지·중단 복구·삭제는 격리된 Codex 저장소에서 검증합니다. 실제 계정 이어쓰기, 두 번째 물리 PC와 모바일은 별도 검수가 필요합니다. [상세 호환성](compatibility.md)을 참고하세요.
