# Codex Manager 사용 안내

## 설치와 업데이트

[Windows 설치파일](https://github.com/contentriumkorea/codex-manager/releases/download/installer-v1/Codex-Manager-Setup.exe)은 약 2.5 MB이며 실행할 때 최신 정식 본체를 내려받습니다. 예전에 받은 설치파일도 계속 사용할 수 있습니다. 설치할 때는 인터넷과 본체를 저장할 공간이 필요합니다.

설치 없이 쓰려면 [포터블 ZIP](https://github.com/contentriumkorea/codex-manager/releases/latest/download/Codex-Manager-Windows-x64.zip)을 새 폴더에 풀고 `CodexManager/CodexManager.exe`를 실행하세요. 실행 파일과 `_internal` 폴더를 함께 보관합니다. 처음 실행할 때 포함 구성요소 이용약관을 확인합니다.

시작 시 새 버전 확인과 미리 다운로드를 진행합니다. 준비가 끝나면 공통 업데이트 버튼에서 설치합니다. 설정에서 자동 확인을 끌 수 있으며 수동 확인은 계속 사용할 수 있습니다. 관리 작업이 진행 중이면 먼저 완료하거나 취소하세요.

## 탐색기처럼 정리하기

프로젝트를 선택하면 대화와 파일을 전환해 볼 수 있습니다. 여러 항목은 Ctrl·Shift로 선택합니다. 열 제목을 누르면 오름차순·내림차순이 바뀝니다. 프로젝트·대화를 대상 프로젝트로 끌어 놓으면 합치거나 소속을 옮깁니다. 대상 프로젝트 이름을 유지합니다.

| 조작 | 기능 |
| --- | --- |
| F2 | 선택한 프로젝트·대화·파일 이름 변경 |
| Delete | 선택 항목 삭제 |
| Shift+Delete | 프로젝트·대화의 완전 삭제 확인 |
| Ctrl+A | 현재 목록 전체 선택 |
| Ctrl+C / Ctrl+X / Ctrl+V | 파일 복사·잘라내기·붙여넣기, 프로젝트·대화 선택 보관과 대상에 이동·병합 |
| Ctrl+Z | 최근 복구 가능한 작업 되돌리기 · 저장소 간 전송 제외 |
| Ctrl+F | 목록 검색 |
| Enter / Backspace | 선택 항목 열기 / 파일 상위 폴더 |

입력창을 편집하는 동안에는 입력창의 일반 단축키를 사용합니다. 프로젝트 표시 이름을 바꿔도 실제 폴더 이름은 유지합니다. 대화를 여러 개 선택하면 찾기·바꾸기와 접두사·접미사로 제목을 정리합니다.

## 대화 표시와 실제 연결

기본 목록과 개수에는 일반 대화만 표시하며 보관된 대화도 포함합니다. 표시 범위에서 **내부 포함**을 선택하면 하위 에이전트·검토 기록도 확인할 수 있습니다. **보관 제외**는 보관된 대화의 표시만 끕니다. 숨긴 내부 기록은 삭제하지 않으며 백업과 전송 의존성에 계속 포함합니다.

대화의 상태에서 **실제 연결**, **폴더 기준 · 표시만**, **원래 대화 기준 · 표시만**을 구분합니다. 폴더나 부모 대화를 통한 표시는 저장된 프로젝트 소속을 바꾸지 않습니다. **미지정·연결 확인**에는 프로젝트 없음으로 설정된 대화, 여러 프로젝트가 같은 폴더를 쓰는 경우, 원래 프로젝트가 없거나 다른 기기에 연결된 경우를 구분해 표시합니다. 같은 폴더를 쓰는 프로젝트 중 하나를 임의로 선택하지 않습니다.

같은 저장소에서 프로젝트를 이동·합치기·삭제할 때 표시만 된 대화가 실제 작업 범위에서 빠질 수 있으면, 기존 확인 다음에 대상 대화의 이름·ID·근거를 보여 줍니다. **연결하고 진행**을 누르면 실제 연결을 별도 작업 내역에 기록한 뒤 요청한 작업을 수행합니다. 이 확인을 취소하면 연결을 변경하지 않습니다. 중단 시 작업 내역을 확인하고, 되돌릴 때는 이후 이동·합치기·삭제를 먼저 복구한 다음 **표시된 대화 연결 확인**을 복구합니다. 이전 형식 프로젝트는 안내에 따라 이름 변경을 한 번 완료해 연결을 갱신한 뒤 진행할 수 있습니다.

백업과 저장소 간 전송 미리보기에는 표시만 된 대화와 내부 의존성도 포함됩니다. 백업의 원래 소속은 그대로 기록하며 백업만으로 실제 연결을 변경하지 않습니다. 다른 기기·명시적인 프로젝트 없음·불명확한 자식 연결은 자동으로 확정하지 않습니다. 내부 기록을 포함해 해당 연결을 확인하고 필요한 대화를 명시적으로 함께 선택하세요.

## 폴더에 대화 자동 보관

프로젝트를 선택하고 **대화 자동 보관**을 켭니다. 처음 저장 결과를 확인한 뒤 Manager를 실행한 채 작업하세요. 변경된 대화를 주기적으로 보관하며, **지금 보관**으로 직접 저장할 수도 있습니다. 최소화한 상태에서도 작동하지만 Manager를 완전히 종료하면 자동 보관도 중지됩니다.

실패하면 마지막 정상 보관본을 유지하고 5·10·20·40·60분 간격으로 다시 시도합니다. 재실행해도 재시도 일정이 유지됩니다. 대화나 연결 폴더 내용이 바뀌면 대기 없이 다시 확인하며, **지금 보관**으로 즉시 재시도할 수 있습니다. 마지막 성공 시각은 이 컴퓨터의 현지 시각으로 표시합니다.

일반 파일은 프로젝트 폴더에 그대로 있습니다. `.codex-manager`에 대화 사본·연결 정보·검증 정보를 저장하므로 폴더 전체를 복사하면 함께 이동합니다. 파일 보기에서는 일반 파일을 확인하고 기본 프로그램으로 엽니다. 자동 보관을 위해 일반 파일을 다시 압축하지 않습니다.

추가로 연결한 외부 작업 폴더는 검증한 사본으로 함께 담습니다. 복원할 때는 프로젝트 폴더 아래 일반 작업 폴더로 꺼내 연결합니다. 추가 폴더의 용량만큼 보관 공간이 필요할 수 있습니다. 변경 없는 대화 사본은 재사용하고 정상 보관본은 최근 두 세대를 유지합니다. 변경·교체·소유권이 불확실한 옛 항목은 자동 삭제하지 않고 유지 경고를 표시합니다.

**마지막 성공 시각**과 **최근 저장 실패**는 구분해서 확인하세요. 이전 정상 보관본이 있어도 최근 저장이 실패하면 최신 작업까지 보관됐다는 뜻은 아닙니다. 손상된 대화, 없는 작업 폴더, 독립 첨부·해결되지 않은 참조가 있으면 원인을 표시하며 완료로 처리하지 않습니다. 원본 대화는 수리하거나 삭제하지 않습니다.

## 선택형 목적지 탐색기

기본 화면은 탐색기 한 개입니다. 우측 상단 **분할 화면 열기** 아이콘을 누르면 오른쪽에 목적지 폴더 탐색기가 열립니다. 아이콘을 다시 누르면 닫히며 표시 방식은 다음 실행에도 유지됩니다.

1. 주 화면에서 옮길 프로젝트나 일반 파일을 선택합니다. Ctrl·Shift로 여러 항목을 선택할 수 있습니다.
2. 오른쪽에서 폴더를 선택하거나 경로를 입력하고, 하위 폴더·상위 폴더를 탐색해 목적지를 정합니다. 검색으로 표시된 폴더를 찾을 수 있습니다.
3. 이동·복사를 선택하고 원본·목적지와 처리 범위를 확인한 뒤 실행합니다. 복사·검증 중에는 진행률·전송 속도·경과 시간을 확인하고 취소할 수 있습니다.

프로젝트 합치기와 대화 소속 이동·이름 변경·삭제는 주 관리 화면에서 처리합니다. 오른쪽은 목적지 선택에 사용합니다. 보호된 저장소, 겹치는 경로, 사용 중인 작업 폴더와 충돌하는 파일은 자동으로 덮어쓰지 않습니다.

## 다른 컴퓨터에서 폴더 열기

1. 원래 컴퓨터에서 **지금 보관**을 실행하고 최근 저장이 성공했는지 확인합니다.
2. 숨김 폴더 `.codex-manager`를 포함해 프로젝트 폴더 전체를 외장하드나 다른 컴퓨터로 복사합니다.
3. 새 컴퓨터에서 Codex 로그인을 마친 뒤 Codex 앱과 관련 CLI 작업을 종료합니다.
4. Manager의 **폴더 열기**에서 프로젝트 폴더 또는 프로젝트들을 모아 둔 보관 상위 폴더를 선택합니다.
5. 발견한 프로젝트의 대화 개수·연결 폴더·검증 결과를 확인하고, 새 프로젝트로 복원하거나 기존 프로젝트에 합칠지 선택합니다.
6. 복원을 완료하면 일반 파일은 선택한 폴더에서 사용하고 대화의 현재 작업 경로는 새 위치에 연결됩니다. Codex를 다시 열어 작업을 확인합니다.

과거 대화 문장에 등장하는 경로는 그대로 보존합니다. 같은 ID의 대화가 있으면 내용·제목·보관 상태·연결까지 확인합니다. 일치하는 기록은 유지하고, 다른 내용은 충돌로 표시해 덮어쓰지 않습니다. 새 프로젝트로 복원한 뒤에도 같은 보관 흐름을 이어가도록 연결합니다. 기존 프로젝트에 합치면 대상 프로젝트 이름을 유지합니다.

복원이 중단되면 **작업 내역·복구**에서 같은 작업을 이어서 진행하세요. 복원 후 수정한 파일이나 다른 대화는 덮어쓰지 않습니다. 실제 두 번째 물리 PC의 계정 이어쓰기와 모바일 표시는 별도 검수가 필요합니다.

### 기존 형식 백업 가져오기

이전 버전에서 만든 백업은 **가져오기 → 백업 위치 → 백업 찾기**를 사용합니다. 백업 폴더나 백업들을 모아 둔 상위 폴더를 선택하고, 작업 파일을 저장할 위치 및 새 프로젝트·기존 프로젝트 병합을 확인합니다. 이 방식은 원본 백업에서 새 작업 위치로 파일을 복사합니다. [호환성 및 제한](compatibility.md)을 확인하세요.

이전 버전에서 시작한 저장소 간 전송 기록도 **작업 내역·복구**에서 확인합니다. 완료된 저장소 간 전송에는 일반 되돌리기·Ctrl+Z를 제공하지 않습니다. 중단된 전송의 보존 후 안전 종료에 관한 안내는 이 문서 하단을 확인하세요.

## 폴더 이동과 원본 정리

프로젝트의 이동·합치기에서 폴더 이동을 선택하고 원본 폴더마다 새 위치를 지정합니다. 파일 복사·검증과 대화 연결 확인을 마친 뒤에만 원본 정리를 진행합니다. 공유 폴더나 보조 작업 폴더, 보호된 저장소와 연결 경로는 검사하며 확인되지 않은 원본은 지우지 않습니다.

파일 이동은 선택한 대상에 복사하며 C드라이브에 프로젝트 전체를 한 번 더 복제하지 않습니다. 되돌리기용 검증 정보는 Manager 설정 폴더에 남습니다. 이동 후 대상 파일이나 연결을 수정했다면 현재 작업을 보호하기 위해 되돌리기를 거부할 수 있습니다.

## 삭제와 복구

프로젝트·대화 삭제 창에서 기본 삭제와 **완전 삭제**를 구분합니다. 기본 삭제는 로컬에 대화 복구 사본을 자동 보관합니다. 매번 복구 위치를 선택할 필요가 없습니다. 완전 삭제는 복구 사본과 휴지통을 사용하지 않으며 앱에서 되돌릴 수 없습니다. 디스크의 보안 덮어쓰기 기능은 아닙니다.

프로젝트 삭제는 포함된 대화와 내부 자식 대화도 처리합니다. 작업 폴더와 파일은 유지합니다. 작업 파일은 파일 탭에서 별도로 정리하세요. 파일 삭제는 로컬 복구 보관 후 되돌릴 수 있습니다.

**작업 내역·복구**에서 복구할 작업을 선택합니다. 중단된 가져오기는 이어서 가져오기를 사용합니다. 삭제·연결 정리 중단 후에는 처리된 결과를 확인하고 제공되는 계속 진행·현재 상태 유지 기능을 사용합니다. 이후 새로 만든 파일이나 수정한 대화는 덮어쓰지 않습니다.

## 저장 위치와 저장소 연결

Manager 설정과 작업 내역은 `%LOCALAPPDATA%/ProjectConversationManager`에 있습니다. Codex의 실제 대화는 선택한 Codex 저장소에 있으며, 자동 보관을 켠 프로젝트 폴더의 `.codex-manager`에 대화 사본과 연결 정보를 함께 둡니다. 일반 작업 파일은 프로젝트 폴더에서 사용합니다. 프로그램 ZIP에는 이 사용자 데이터가 포함되지 않습니다.

**설정·저장소**에서 이전 저장소가 남아 있는 상위 폴더를 검색하거나 경로를 직접 연결합니다. 저장소 전환은 파일 이동이 아닙니다. 자동 검색에서 찾지 못하면 저장소가 실제로 있던 상위 폴더를 지정하세요. Codex 실행 파일은 자동으로 찾으며 필요한 경우 설정에서 경로를 지정할 수 있습니다.

조회와 백업은 Codex 실행 중에도 사용할 수 있습니다. 연결 변경·가져오기·삭제·폴더 변경 작업 전에는 Codex 앱과 관련 CLI 작업을 종료하세요. 새 컴퓨터의 계정 로그인과 모바일 동기화는 별도 확인이 필요합니다.
