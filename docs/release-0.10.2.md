# Codex Manager 0.10.2

Windows 설치 파일: `Codex-Manager-Setup.exe`.

백업·프로젝트 이동·가져오기와 파일 복사 작업의 진행 창을 개선했습니다.

- 현재 단계의 진행률, 처리 용량, 전송 속도(MB/s), 총 경과 시간, 복사 단계의 예상 남은 시간을 표시합니다.
- 여러 프로젝트나 파일을 처리할 때 현재 항목과 순서, 작업 중인 파일을 표시합니다.
- 파일 복사가 100%에 도달한 뒤에도 대화 저장, 검증 목록 생성, 전체 백업 검증의 진행 상황이 이어집니다. 검증 처리량은 파일을 읽는 동안에도 갱신됩니다.
- 느린 디스크 검사 중에도 화면의 경과 시간과 최신 단계가 갱신됩니다. 취소 요청 시 작업 창을 유지하고 정리 중임을 안내합니다.

남은 시간은 현재 복사 단계의 추정치이며 검증과 대화 연결 시간은 별도입니다. 원본 변경 검사, 충돌 방지, 복사본 검증과 중단 작업 복구를 유지합니다.

다른 컴퓨터에서 이전 버전으로 진행 중인 백업에는 화면 개선이 소급 적용되지 않습니다. 그 작업을 완료하거나 취소한 뒤 이 설치 파일로 업데이트하세요.

검증: 전체 테스트 248개 통과, 별도 Windows 연동 테스트 2개 통과. 진행 창 테스트 4개는 Windows 환경에서도 추가 확인했습니다. 실제 파일 복사·백업 무결성·취소·느린 검증 중 화면 갱신을 격리 데이터로 검증했습니다. 패키지 업데이트 및 0.10.2 실행, 사용자 PC 설치, 시작 메뉴·작업 표시줄 등록, 설정·작업 기록 유지도 확인했습니다. 다른 물리 PC에서 진행 중인 백업은 직접 확인하지 않았습니다.

GitHub 게시는 인증 오류(HTTP 401)로 보류되어 있습니다. 로컬 설치파일을 사용할 수 있습니다.
