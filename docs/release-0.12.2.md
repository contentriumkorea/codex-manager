# Codex Manager 0.12.2

**[Windows 설치 프로그램](https://github.com/contentriumkorea/codex-manager/releases/download/installer-v1/Codex-Manager-Setup.exe)** · **[포터블 ZIP](https://github.com/contentriumkorea/codex-manager/releases/latest/download/Codex-Manager-Windows-x64.zip)**

프로젝트에 속한 대화가 미지정으로 보이거나 내부 에이전트 기록 때문에 미지정 개수가 과하게 표시되는 문제를 수정했습니다.

- 실제 연결을 우선하고 유일한 작업 폴더·원래 대화 관계를 표시용 연결로 복원합니다. 각 대화에서 표시 근거와 확인이 필요한 이유를 볼 수 있습니다.
- 기본 목록은 일반 대화와 보관된 대화를 표시합니다. 한 개의 표시 범위 메뉴에서 내부 기록 포함과 보관 제외를 선택합니다.
- 백업에는 표시만 된 대화와 내부 기록도 포함합니다. 프로젝트 이동·합치기·삭제 전에 필요한 실제 연결을 확인하고 복구 가능한 별도 작업으로 기록합니다.
- 프로젝트 없음 설정, 다른 기기 연결과 공유 폴더의 불명확한 소속을 임의로 변경하지 않습니다.

두 탐색기의 독립적인 저장소·검색·선택과 저장소 간 이동·복사, 좁은 사이드바 표시를 유지합니다. 기존 고정 설치 프로그램을 계속 사용합니다.
