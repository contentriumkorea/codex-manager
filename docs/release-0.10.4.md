# Codex Manager 0.10.4

**[Windows 설치 프로그램 · 약 2.5 MB](https://github.com/contentriumkorea/codex-manager/releases/download/installer-v1/Codex-Manager-Setup.exe)** · **[포터블 ZIP](https://github.com/contentriumkorea/codex-manager/releases/latest/download/Codex-Manager-Windows-x64.zip)**

설치와 업데이트 배포 과정을 점검했습니다. 기존에 받은 작은 설치파일도 계속 최신 앱을 설치합니다.

- 첫 페이지에서 설치형과 포터블을 바로 구분하고 받을 수 있습니다. 설정과 대화가 저장되는 위치, 다른 컴퓨터로 옮기는 방법을 안내합니다.
- 프로그램·설정 경로가 길 때 작업표시줄 아이콘 등록이 실패하던 경계 조건을 수정했습니다. 한글과 이모지가 포함된 경로도 검사합니다.
- 포터블을 새 폴더에서 직접 실행하고, 설치 등록이나 바로가기가 생기지 않는지 검사한 뒤 배포합니다.
- 배포 파일 전체의 무결성과 사용자 데이터 제외 여부를 확인합니다. 공개 다운로드·설치·업데이트·제거 검증에 실패하면 이전 정상 배포로 복구합니다.

프로젝트·대화 관리 방식과 저장 형식은 유지합니다. 프로젝트와 대화를 다른 컴퓨터로 옮길 때는 앱의 **보내기 / 가져오기**를 사용하세요. 프로그램 ZIP만으로 작업 데이터가 함께 옮겨지지는 않습니다.

Windows x64용입니다. 실제 계정의 다른 물리 PC 이어쓰기와 모바일 표시는 별도 검수가 필요합니다. 자세한 내용은 [사용 안내](https://github.com/contentriumkorea/codex-manager/blob/main/docs/user-guide.md)를 참고하세요.
