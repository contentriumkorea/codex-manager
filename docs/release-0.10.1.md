# Codex Manager 0.10.1

Windows 설치 파일: `Codex-Manager-Setup.exe`.

대화 삭제 후 Codex 앱의 목록에 제목이 남는 문제를 수정했습니다. 원본 삭제가 확인되면 앱이 별도로 저장하는 제목 목록도 함께 정리합니다. 진행 중이던 목록 갱신 작업이 삭제한 제목을 다시 추가하지 않도록 처리합니다.

연결된 하위 대화도 함께 처리하며, 다른 컴퓨터의 대화와 ChatGPT 대화 목록은 유지합니다. 목록 저장소가 잠겼거나 지원하지 않는 형식이면 원본을 삭제하기 전에 중단합니다. 삭제 도중 오류가 나더라도 이미 삭제된 항목의 제목은 정리합니다.

이번 수정은 앞으로 실행하는 삭제 처리에 적용됩니다. 기존에 남아 있는 항목은 해당 대화와 저장소를 확인한 뒤 별도로 정리해야 합니다.

검증: 전체 테스트 235개 통과, 별도 Windows 연동 테스트 2개 통과. 격리 저장소에서 실제 Codex 삭제 API로 제목 잔존을 재현한 뒤 수정 결과를 확인했습니다. 패키지 업데이트·새 버전 실행·설정 유지 검증과 사용자 PC의 0.10.1 설치 확인을 마쳤습니다. 실제 사용자 대화는 테스트나 정리 대상으로 변경하지 않았습니다. GitHub 공개 배포는 아직 진행하지 않았습니다.
