# Codex Manager 0.9.0

사용자가 승인한 세 가지 흐름을 함께 개선한다: 항상 보이는 프로젝트 트리, 선택에 맞춘 작업바, 결과에서 복구·재시도로 이어지는 작업 내역.

## 구현 범위

- 기존 PySide6 구조와 밝은 글래스 UI 유지. 프로젝트/폴더 트리, 저장소별 즐겨찾기, 트리 검색, 드롭 대상 연결.
- 파일·대화·프로젝트 선택을 구별하고 숨겨진 목록/다른 폴더 선택으로 작업하지 않음. 기본 단축키와 확인 흐름 유지.
- 복수 프로젝트 백업. 이름 충돌 시 새 폴더, 항목별 검증, 성공한 백업만 등록.
- 기존 SQLite 저널을 이용한 최근 작업/경로/오류 표시. 단일 작업 결과에 정확한 작업 ID 연결.
- 일괄 계획을 실행 전에 저장하고 각 결과를 지속 기록. 재시도 이력은 새 작업 생성과 같은 트랜잭션에서 연결. 종료 직전 완료한 이동은 자식 저널, 백업은 이미 기록된 검증 증거로 대조.
- 재시도는 현재 스냅샷으로 대상을 다시 검토하고 사용자에게 확인 내용을 표시. 기존 부분 파일은 덮어쓰지 않음.

## 검증 및 배포 기준

기능 테스트는 격리된 폴더·Codex 저장소를 사용한다. 숨겨진 선택, 저장소 전환, 복수 백업 부분 실패, 프로세스 종료, 완료 기록 직전 종료, 재시도 중 종료를 검증한다. 전체 회귀 테스트와 Windows 화면 검수 후 패키징한다. 공개 릴리스의 해시와 이전 버전 업데이트 버튼을 검증한 다음 로컬 설치본을 교체하고 설정 보존·새 버전 실행을 확인한다.

사용자 원본 프로젝트/대화는 시험용으로 이동·삭제하지 않는다. 실제 모바일과 두 번째 물리 PC 동기화는 검증 범위에 포함하지 않는다.
