# Codex Manager 0.11.0

**[Windows 설치 프로그램 · 약 2.5 MB](https://github.com/contentriumkorea/codex-manager/releases/download/installer-v1/Codex-Manager-Setup.exe)** · **[포터블 ZIP](https://github.com/contentriumkorea/codex-manager/releases/latest/download/Codex-Manager-Windows-x64.zip)**

프로젝트·대화·파일을 함께 정리하는 화면과 저장소 처리 구조를 개선했습니다. 이전에 받은 작은 설치파일은 그대로 최신 본체를 설치합니다.

- 밝은 탐색기 화면에서 이름 변경, 여러 항목 선택, 끌어 놓기, 열 제목 정렬과 기본 단축키를 사용합니다.
- 현재 Codex의 프로젝트 연결과 여러 작업 폴더를 함께 읽고, 이전 저장소의 연결 정보도 확인합니다.
- 백업 상위 폴더에서 가져올 프로젝트를 찾고, 새 프로젝트로 가져오거나 기존 프로젝트에 합칩니다. 가져올 폴더를 각각 확인하고 수정할 수 있습니다.
- 파일 이동은 선택한 대상에 복사하며, C드라이브에 프로젝트 전체를 다시 복제하지 않습니다. 전송 속도와 경과 시간, 남은 시간을 표시합니다.
- 중단된 가져오기·삭제·연결 정리와 되돌리기 처리를 보강했습니다. 이후 수정한 파일과 대화는 덮어쓰지 않습니다.
- 시작할 때 새 버전을 확인하고 미리 준비합니다. 다운로드 준비가 끝나면 업데이트 버튼에서 교체 후 다시 실행합니다.

기존 설정과 작업 내역을 유지합니다. 대화와 작업 파일은 프로그램 ZIP에 포함되지 않으므로, 다른 컴퓨터로 옮길 때는 앱의 **백업 / 가져오기**를 사용하세요.

Windows x64용입니다. 별도 실행 구성요소 설치가 필요하지 않도록 본체에 포함하므로 설치기가 받는 본체와 포터블 ZIP은 설치파일보다 큽니다. 처음 실행할 때 포함 구성요소의 이용약관을 확인합니다. [개인정보·구성요소 안내](https://github.com/contentriumkorea/codex-manager/blob/main/docs/third-party.md)를 참고하세요.

실제 계정으로 다른 물리 PC에서 이어쓰기, 모바일 표시와 여러 Windows 배율 조합은 별도 검수가 필요합니다. [호환성 및 제한](https://github.com/contentriumkorea/codex-manager/blob/main/docs/compatibility.md)을 확인하세요.
