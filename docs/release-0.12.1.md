# Codex Manager 0.12.1

**[Windows 설치 프로그램 · 약 2.5 MB](https://github.com/contentriumkorea/codex-manager/releases/download/installer-v1/Codex-Manager-Setup.exe)** · **[포터블 ZIP](https://github.com/contentriumkorea/codex-manager/releases/latest/download/Codex-Manager-Windows-x64.zip)**

좁은 탐색기에서도 사이드바 메뉴와 저장소 이름을 읽기 쉽도록 표시를 수정했습니다.

- 프로젝트·미지정 대화 수가 커져도 메뉴 이름과 숫자가 본문에 겹치지 않습니다.
- 사이드바 너비를 확보해 프로젝트 이름을 더 길게 표시합니다.
- 좁은 탐색기에서는 저장소 이름과 선택 목록을 두 줄로 배치하고 연결 버튼을 유지합니다.

두 탐색기의 독립적인 저장소·검색·선택, 저장소 간 이동·복사와 기존 설정·작업 내역을 유지합니다. 설치 프로그램은 기존 고정 다운로드 주소를 그대로 사용합니다.
