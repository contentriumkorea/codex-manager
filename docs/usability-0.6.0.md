# Codex Manager 0.6.0 사용성 개선

승인 범위: 기획·설계·구현·검증·배포·현재 컴퓨터 업데이트. 기존 밝은 글래스 UI와 파일 중심 구조를 유지한다.

## 사용 흐름
1. 프로젝트를 선택하면 상단 이름 변경 버튼 또는 F2로 이름을 고친다. 실제 폴더명은 유지한다.
2. 모든 대화 화면에서 프로젝트·제목·경로 검색과 전체/진행/보관 필터, 최근 작업/이름/프로젝트 정렬을 사용한다.
3. 대화를 선택하면 제목 변경·소속 이동·삭제·복사 기능이 활성화된다. Ctrl+A는 현재 표시된 목록만 선택한다.
4. 하나의 제목은 입력 즉시 검증하고, 여러 제목은 앞/뒤 문구 추가 또는 문자열 바꾸기를 변경 전후 표로 확인한다. 빈 제목·256자 초과·제어 문자를 거부한다. 변경 없는 요청은 저장하지 않는다.
5. 일괄 변경은 모든 제목과 최신 기록을 검증한 뒤 시작한다. 중단되면 작업 복구에 남으며, 이후 별도 수정된 제목은 덮어쓰지 않는다. 완료된 제목 변경도 작업 복구에서 되돌린다.
6. 검색·필터로 숨겨진 항목은 선택 작업에 포함하지 않는다. 백업은 화면 필터에 영향받지 않는다.

## 검증 및 납품
합성 저장소 테스트만으로 변경 기능을 검증한다. 실제 사용자 대화·폴더를 테스트 목적으로 변경하지 않는다. 단위·UI·격리 통합 테스트, 작은 창/전체 대화/제목 변경 화면 캡처, 빌드 및 공개 다운로드 검증 후 설치 버전을 교체한다. 모바일 동기화는 확인되지 않은 것으로 명시한다.
