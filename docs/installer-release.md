# Windows 설치 프로그램

## [⬇ Codex Manager 설치하기](https://github.com/contentriumkorea/codex-manager/releases/download/installer-v1/Codex-Manager-Setup.exe)

약 2.5 MB의 설치 프로그램입니다. 실행하면 최신 정식 버전을 자동으로 내려받고 검증한 뒤 설치합니다. 인터넷 연결이 필요합니다.

**이 설치파일을 보관해 두세요.** 다음 버전이 나와도 다시 받을 필요 없이 같은 파일로 최신 버전을 설치할 수 있습니다. 설치 후에는 앱의 **업데이트** 기능을 사용하세요.

설치 위치를 선택할 수 있으며 시작 메뉴와 Windows 앱 제거 기능을 제공합니다. 기존 프로그램이 실행 중이면 작업을 마치고 종료한 뒤 설치하세요. 설정·프로젝트·대화·백업은 유지합니다.

이 릴리스에는 고정 설치파일만 있습니다. [최신 앱 버전과 변경 내용](https://github.com/contentriumkorea/codex-manager/releases/latest)은 별도 릴리스에서 관리합니다. GitHub가 자동 생성하는 Source code ZIP은 설치파일이 아닙니다.
