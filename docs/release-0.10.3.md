# Codex Manager 0.10.3

## [⬇ Windows 설치 프로그램 다운로드](https://github.com/contentriumkorea/codex-manager/releases/download/installer-v1/Codex-Manager-Setup.exe)

**약 2.5 MB의 온라인 설치 프로그램**으로 바뀌었습니다. 한 번 받아 두면 실행할 때마다 최신 정식 버전을 자동으로 확인하고 내려받아 설치합니다. 인터넷 연결이 필요합니다.

- 설치파일은 별도의 `installer-v1` 릴리스에서 고정 주소로 제공합니다. 앱 버전이 바뀌어도 다시 만들거나 교체하지 않습니다.
- 이전에 공유한 다운로드 주소도 계속 작동하도록 이 릴리스에는 동일한 설치파일의 복사본을 함께 제공합니다.
- 이 릴리스의 ZIP은 앱 본체, `update.json`은 앱 업데이트 정보, `install.ini`는 설치 프로그램이 읽는 버전 정보입니다. 일반 사용자는 위 설치 링크만 이용하면 됩니다.
- 다운로드와 압축 해제 진행 상태를 표시합니다. 검증에 실패하면 기존 설치를 유지하고 다시 시도할 수 있습니다.
- 설치 위치, 시작 메뉴, 앱 제거, 기존 앱 업데이트와 사용자 설정 보존을 지원합니다.
- 이전 로컬 배포의 대화 삭제 후 제목 정리, 백업·이동 속도와 경과 시간, 복사 완료 후 검증 진행률 개선을 포함합니다.

기존 사용자는 앱의 **지금 업데이트**를 눌러도 됩니다. 백업·파일 이동 중에는 해당 작업이 끝난 뒤 업데이트하세요.

[배포·설치 검증 결과](release-verification-0.10.3.md): GitHub 전체 테스트 259개와 설치·업데이트·제거, 공개 다운로드 검증을 통과했습니다.
