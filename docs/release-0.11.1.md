# Codex Manager 0.11.1

**[Windows 설치 프로그램 · 약 2.5 MB](https://github.com/contentriumkorea/codex-manager/releases/download/installer-v1/Codex-Manager-Setup.exe)** · **[포터블 ZIP](https://github.com/contentriumkorea/codex-manager/releases/latest/download/Codex-Manager-Windows-x64.zip)**

Windows에서 앱 내부 목록의 끌어 놓기가 차단되던 문제를 수정했습니다.

- 대화를 왼쪽 프로젝트로 끌어 놓으면 프로젝트 소속을 옮깁니다.
- 프로젝트를 다른 프로젝트에 끌어 놓으면 확인 후 합칩니다. 대상 프로젝트 이름과 실제 파일 위치는 유지합니다.
- 파일·폴더를 앱 안의 대상 폴더로 끌어 놓으면 이동합니다. Ctrl을 누르면 복사합니다.
- Ctrl·Shift로 여러 항목을 선택한 뒤 함께 끌어 놓을 수 있습니다.

기존 설정과 작업 내역을 유지합니다. [호환성 및 제한](https://github.com/contentriumkorea/codex-manager/blob/main/docs/compatibility.md) · [구성요소 안내](https://github.com/contentriumkorea/codex-manager/blob/main/docs/third-party.md)
